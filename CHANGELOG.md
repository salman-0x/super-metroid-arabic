# Changelog

## 1.0.0
First public release, by Mr S. Distributed as a BPS patch (no ROM data inside). Translated: message boxes, file select (+ copy/clear dialogs), OPTION MODE, intro story, GAME OVER, pause screens
(labels, 14 item names, map buttons, 7 area names), HUD. Not translated by design: title logo, ending lines, staff credits, L/R, Japanese text mode.
